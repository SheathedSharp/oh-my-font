# oh-my-font

A home for font projects by **zayju**. The first planned release contains the **Lihui** and **Zixian** families.

**Status: release preparation. Font sources and compiled font packages have not been imported into this repository. There is no published font release yet.**

The intended distribution model is source and documentation in Git, with ready-to-use font packages in GitHub Releases. Commercial use is a release goal; the applicable license, provenance and release validation must be established before publishing fonts. This preparation notice is not a font license or a compatibility claim.
