# LihuiT / zayJu 0.400 — approved redesign release

The owner approved PR #10 at `4640e2b38bc20b72e4f5584113208fa819b5adc9` and
explicitly authorized merge and publication. It was merged as
`b5de4cbb6bc794e6801f7c5dfbd04ebaa64f044b`.

Release scope is **two Regular 400 upright faces**, one per family, in TTF / OTF /
WOFF2. Each includes the accepted 810-codepoint / 986-glyph reference repertoire.
No historic 0.301 styles are mixed into this release, and no unapproved weights or
Obliques are synthesized. The old 0.301 release and tags remain intact.

This release integration changes official names, version metadata, default build,
packaging, checks and website inventory. It must not change approved UFO outlines,
metrics, anchors or features. `config/approved-reference.json` locks the accepted
inputs. Exact-candidate checks compare every emitted glyph and layout table to a
fresh compile of those approved sources, in addition to OTS, shaping and renderer
checks. OFL and author/source attribution are preserved.

A draft release is uploaded and verified before publication; the published
assets are downloaded into a new directory and verified again. The website uses
the released Website ZIP rather than rebuilding an unrelated source revision.
