# LihuiT & zayJu 0.400 — approved complete redesign

**已验收重绘稿正式发布：LihuiT Regular + zayJu Regular，均为 400 正体。**
每款 **810 个编码字符、986 个字形、21 个 OpenType 功能**。

This release publishes the owner-approved full redesign from PR #10. The release
build promotes official names/version metadata while preserving every accepted
outline, advance, anchor-derived placement and layout table. No historic 0.301
outlines or unapproved synthetic weights are mixed into the new design.

## 下载 / Downloads

**TTF** and **OTF** are alternative desktop formats: install one, not both.
**WOFF2** includes webfonts, CSS and a small example page.
**Website** contains the complete self-contained specimen deployed at fonts.zayju.de.
`SHA256SUMS.txt`, `BUILD-MANIFEST.json` and `QA.json` bind all assets to the exact
source commit and checked font bytes. Each ZIP includes OFL/source notices and
its own internal checksums. GitHub's automatic source archive is not the font
installation package.

## 升级说明 / Migration

停用旧 LihuiT / zayJu 字体后再安装新版，避免同名字体的缓存冲突。
**本版本只有两款 Regular 400 正体**；其他七档字重和 Oblique 没有发布，也没有
通过简单膨胀或倾斜合成。旧 v0.301 的 tag 和下载包保持不变，可用于历史项目，
但不应与本次新设计混用为同一套一致的多字重字族。

Deactivate older installed versions before installing the redesign. Additional
weights/italics require their own design approval and are outside this release.

## 完整性 / Verification

The official candidates are checked against fresh approved-source compiles,
including all glyphs and OpenType layout. Full source/serialized geometry,
OpenType Sanitizer, encoded-character shaping, 17,784 forced-decomposition /
stylistic-set comparisons, lossless WOFF2, independent-directory reproducibility,
native macOS and actual browser font loading are verified. Packaging is checked
before publication and the published downloads are verified again.

FontBakery's **scoped gate passes, not the entire raw universal profile**. The
four existing Sigma case-coverage FAIL results and all remaining WARN results
are retained in QA.json. No expanded exception or fabricated Greek glyph hides
them. Full Greek/Cyrillic/Han, variable fonts and monospaced coding are not claimed.
