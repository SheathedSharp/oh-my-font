# LihuiT & zayJu 0.500 — first multi-weight redesign

**第一套基于已验收 0.400 Regular 的完整多字重家族。**
LihuiT（正文）与 zayJu（展示）各有正体 **100、300、400、500、600、700、800、900**，以及每个字重的 **10° Oblique**。共 32 款样式。每款 **810 个编码字符、986 个字形、21 个 OpenType 功能**。

This is the first complete multi-weight family drawn from the approved 0.400 redesign. Regular 400 upright is that approved drawing and is not retargeted. Every other upright is its own stored master (stems, joins, counters, and the review letters B, M, R, a, g, e, 2, 3, 6, 8, 9). Oblique is a 10° slant of that weight’s master. It is **not** a separately drawn Italic. Design notes: `docs/design/0.500-weights.md`.

These outlines do not come from the rejected 0.301/0.302 weight experiments or from PR #8.

## 下载 / Downloads

**TTF** and **OTF** are the same desktop identities: install one, not both.
**WOFF2** is for the web. **Website** is the specimen.
`SHA256SUMS.txt`, `BUILD-MANIFEST.json` and `QA.json` bind the assets to the tagged commit. Every ZIP contains OFL, attribution, authors, FONTLOG and its own checksums. GitHub’s automatic source archive is not the font package.

## 升级说明 / Migration

停用已安装的旧 LihuiT / zayJu，再安装本版本，避免字体缓存冲突。
**不要把 0.301 的字重和这套 0.500 混用。** 它们不是同一套设计。
TTF 与 OTF 只选一种。文件名和排印子族写的是 Oblique；Windows 的旧式 name ID 2 在需要样式链接时仍使用 Italic / Bold Italic，这不表示另有一套手绘斜体。

Deactivate older installs before installing 0.500. Do not mix 0.301 fonts into this family. Pick TTF or OTF. The typographic name is Oblique.

## 完整性与限度 / Verification and limits

Regular 400 upright matches a fresh compile of the approved drawings. Other styles are checked as stored masters. Forced decomposition covers every upright TTF plus Regular and Black Oblique; the remaining Obliques are sampled as documented in `docs/QA-0.500.md`.

FontBakery’s scoped gate still accepts exactly one FAIL per desktop file: missing case partner for U+03A3 (no U+03C3 was invented). Warnings stay in QA.json. This is not full Greek, Cyrillic or Han, not a variable font, and not a monospaced coding family.

Windows 裁切框在每一款上都是 usWinAscent 1606、usWinDescent 626，用来容纳 Black 上叠起来的标记（zayJu `uni1E50` 实测到 y=1606）。排版行距仍是 0.400 Regular 的数值，没有被撑开。

The Windows clip is usWinAscent 1606 and usWinDescent 626 on every style, including Regular, so Black stacked marks (measured to y=1606 on zayJu `uni1E50`) are inside the box. Typographic line spacing stays the 0.400 Regular values.

新字重在打标签之前需要人工看过字重阶梯，尤其是 B、M、R、a、g、e 和数字 2/3/6/8/9，正体和 Oblique 都要看。技术检查通过不等于目检通过。
